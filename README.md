# 개인 알림장 · 학급 알림장 통합 관리자

교사용 개인 알림장입니다. Claude Code 화면에 전달사항과 요청을 입력하고, Claude가 정리한 결과를 확인한 뒤 Google Sheets에 개인 일정과 학급 공지 초안을 만듭니다. 관리자가 확인한 공지만 학생용 학급 알림장에 게시합니다.

## 핵심 흐름

1. Claude 요청 화면에 전달사항과 원하는 정리 방법을 입력합니다.
2. Claude가 만든 `/공지사항 [...]` 결과를 화면에서 확인하고 필요하면 수정합니다.
3. `개인 알림장에 반영`을 누르면 Apps Script가 `앱_개인알림장`에 저장합니다.
4. `[학급]`과 `[학생개별: 이름]`은 `앱_공지사항`에 `검토대기` 초안도 만듭니다.
5. 관리자 화면에서 `위로`·`아래로` 버튼을 필요한 만큼 눌러 전달 순서를 정한 뒤 `순서 저장`을 한 번 누릅니다. `순서가 저장되었습니다.`를 확인한 다음 `게시하기`를 누릅니다.
6. 학생 사이트는 `게시됨` 상태의 전체 공지와 본인 개별 공지만 읽습니다.

개인 알림장 일정은 관리자 로그인 후 카드의 `수정`·`삭제` 버튼으로 관리합니다. 오른쪽 달력은 학사일정 전용이며 개인 알림장의 학급·교과·개인 항목은 자동 반영하지 않습니다. 달력에는 공통 `class-notice/data.js`의 학사일정·공휴일·고사기간·방학만 표시하며, 알림장 내용을 달력에 넣는 기능은 별도로 요청받을 때만 추가합니다.

Claude가 이미 정리한 내용은 `ingestPrepared` 작업으로 저장하므로 Apps Script의 OpenAI 설정과 무관하게 다시 AI 분석하지 않습니다. Claude 연결이 없을 때는 접힌 `Claude 없이 명령어를 직접 반영하기` 입력란을 사용할 수 있습니다.

번호 목록이나 서로 독립된 일정이 들어오면 Claude가 항목 사이를 `---`로 나누고 명령을 반복합니다. Apps Script는 여러 명령 블록과 `1.`, `2.` 형식의 목록을 각각 별도의 개인 알림장 행으로 저장하므로 항목마다 완료 체크할 수 있습니다. `[학급]`과 `[학생개별]` 항목은 검토함에도 각각 별도 초안으로 생성됩니다. 검토함의 위·아래 조작은 화면에서만 진행되며 `순서 저장`을 누른 최종 순서가 Google Sheets와 게시 후 학생 알림장에 적용됩니다.

Claude 요청에는 PDF, Excel `.xlsx`, CSV, 텍스트, PNG·JPG·WebP·GIF 이미지를 최대 5개까지 첨부할 수 있습니다. Excel은 서버에서 읽을 수 있는 텍스트로 변환하고 PDF·이미지는 요청별 임시 폴더에서 읽습니다. 파일은 요청 처리 후 즉시 삭제됩니다.

## Claude Code 브리지

GitHub Pages는 환경변수나 Claude Code 프로세스를 실행할 수 없으므로 `server/`를 Docker 서버로 별도 배포합니다.

```text
개인 알림장(GitHub Pages)
  → Claude 브리지(Node/Docker)
  → Claude Code -p
  → CLAUDE_CODE_OAUTH_TOKEN 자동 인증
  → 정리 결과 확인
  → Apps Script / Google Sheets 반영
```

필수 서버 환경변수:

```env
CLAUDE_CODE_OAUTH_TOKEN=claude_setup_token_값
CLAUDE_BRIDGE_ACCESS_KEY=20자_이상의_별도_접속키
ALLOWED_ORIGINS=https://morningcandy.github.io
```

토큰은 현재 로그인 세션의 내부 파일에서 꺼내지 않습니다. Claude Code에서 `claude setup-token`을 실행해 자동화용 장기 토큰을 새로 만든 뒤 배포 서비스의 Secret에 직접 입력합니다. 자세한 실행 방법은 `server/README.md`를 참고하세요.

`main`에 `server/` 변경이 올라오면 GitHub Actions가 `ghcr.io/morningcandy/class-planner-claude-bridge:latest` 컨테이너 이미지를 만듭니다. 실제 서버에는 이 이미지를 배포하고 위 환경변수를 등록합니다.

## 명령어

```text
/공지사항 [개인]
금요일까지 자동차 보험 갱신하기

/공지사항 [교과]
8월 22일까지 수행평가 계획서 제출

/공지사항 [학급]
내일까지 진로희망 조사서를 제출하도록 안내

/공지사항 [학생개별: 김민수, 이지현]
수행평가 보고서를 금요일까지 다시 제출하도록 안내
```

- `[개인]`: 개인 알림장 `개인`에만 저장
- `[교과]`: 개인 알림장 `교과`에만 저장
- `[학급]`: 개인 알림장 `학급` + 학급 전체 공지 초안
- `[학생개별: ...]`: 개인 알림장 `학급` + 대상 학생 개별 공지 초안

## Google Sheets / Apps Script 설치

1. 관리 시트에서 `확장 프로그램 → Apps Script`를 엽니다.
2. 저장소의 `apps-script.gs` 내용을 Apps Script 편집기에 붙여넣습니다.
3. `setupClassPlanner`를 한 번 실행합니다. 기존 탭은 유지되고 `앱_...` 탭이 추가됩니다. 생략해도 최초의 올바른 관리자 로그인 요청에서 앱 전용 탭과 초기 관리자 토큰을 자동 준비합니다.
4. 시트 메뉴 `학급 플래너 → 관리자 토큰 설정`을 실행해 초기 비밀번호를 개인 비밀번호로 변경합니다.
5. 선택 사항으로 `OpenAI API 키 설정`을 실행합니다. 이 설정은 Claude를 거치지 않고 직접 명령어를 입력할 때만 사용합니다.
6. `앱_학생목록`에 학생 정보를 입력합니다.
7. Apps Script를 웹앱으로 배포합니다.
   - 실행 사용자: 나
   - 액세스 권한: 모든 사용자
8. 배포 URL을 `config.js`의 `apiUrl`과 학생 저장소 `index.html`의 `SHEET_API`에 동일하게 입력합니다.

웹앱을 기존 배포의 새 버전으로 업데이트하면 URL을 유지할 수 있습니다.

기존 사이트가 같은 브라우저에 저장해 둔 `classPlanner.schedule.v2` 일정은 새 관리자 화면의 `기존 일정 가져오기` 버튼으로 `앱_개인알림장`에 한 번 옮길 수 있습니다.

## 앱 전용 시트

- `앱_학생목록`: 학생 ID, 번호, 이름, 개인 코드
- `앱_입력함`: 원문과 AI 분석 결과
- `앱_개인알림장`: 학급·교과·개인 일정
- `앱_공지사항`: 검토 대기·게시·종료 상태와 관리자 지정 표시 순서
- `앱_학생응답`: 학생의 확인·완료 기록
- `앱_변경기록`: 관리자 작업 기록

## 비밀값

관리자 토큰과 OpenAI API 키는 GitHub나 시트 셀에 넣지 않습니다. Apps Script의 Script Properties에만 저장됩니다. 관리자 토큰은 현재 브라우저 탭의 `sessionStorage`에 보관되어 브라우저를 닫으면 사라집니다.

Claude OAuth 토큰도 GitHub, `config.js`, 브라우저에 넣지 않습니다. 배포 서버의 `CLAUDE_CODE_OAUTH_TOKEN` Secret으로만 설정합니다. 화면에 입력하는 `CLAUDE_BRIDGE_ACCESS_KEY`는 OAuth 토큰과 다른 값이며 현재 브라우저 탭에만 저장됩니다.
