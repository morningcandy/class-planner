# 학급 플래너 (선생님용)

2학년 담임 선생님용 학급 운영 플래너입니다. 단일 HTML 파일(`index.html`)로 되어 있고, 외부 라이브러리·서버 없이 브라우저만으로 동작합니다.

## 구성
- 📢 안내사항
- ✅ 오늘 할일 (마감 임박순, 다음날 자동 정리 — 체크 상태는 브라우저에 저장)
- 📋 전체 일정 (담임 / 교과 / 개인)
- 🗓️ 학사일정 달력 (2026학년도 2학기)
- 🗓️ 주간계획 (요일별 자동 집계)
- 🔔 시정표

## 내용 수정
`index.html` 안의 데이터 배열만 고치면 내용이 바뀝니다:
- `NOTICES` — 안내사항
- `TASKS` — 오늘 할일
- `SCHEDULE` — 전체 일정(담임/교과/개인)
- `EVENTS` / `HOLIDAYS` / `PERIODS` — 달력

## 학급(학생) 사이트 연결
`전체 일정`의 **담임** 항목을 학생용 사이트로 보내는 버튼이 있습니다.
학생 앱을 배포한 뒤, `index.html`의 `CLASS_SITE_URL` 값에 그 주소(`https://...`)를 넣으면 버튼이 활성화됩니다.
(학생 앱에는 학생 개인정보가 포함되어 있어, 공개 배포 여부는 개인정보 보호를 검토한 뒤 결정하세요.)

## 배포 (GitHub Pages)
저장소 Settings → Pages → Branch를 `main` / `/(root)`로 지정하면
`https://<사용자명>.github.io/<저장소이름>/` 에서 열립니다.
